# Data policy

Raw audio/video files are intentionally excluded from Git. Store them in a controlled, access-restricted location and reference them through a manifest only.

The example corpus contains synthetic metadata and hand-authored acoustic summaries for contract tests. It is not a scientific dataset and must not be used to support claims about dogs.

Recommended production metadata includes:

- consent, permit, and license status;
- synchronized sensor clocks and calibration records;
- animal, session, site, device, season, and observer identifiers;
- no-call/background windows;
- independent annotations and disagreement records;
- exact dataset and preprocessing version.
